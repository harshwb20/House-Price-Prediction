# House Price Prediction

A Machine Learning-based web application that predicts house prices based on housing and geographical features. Built using Python, Flask, MySQL, and Scikit-learn.

##  Overview

This project allows users to register, log in, and access a personalized dashboard to predict house prices. Users can enter housing-related details and receive an estimated price generated by a trained Machine Learning model.

The application also maintains individual prediction history for each registered user.

##  Features

- **User Authentication:** Sign Up, Login, and Logout functionality.
- **User Dashboard:** Personalized dashboard after successful login.
- **House Price Prediction:** Predicts prices using a trained Machine Learning model.
- **Prediction Results:** Displays the estimated house price.
- **Prediction History:** Stores and displays previous predictions for each user.
- **MySQL Integration:** Stores user details and prediction records.

##  Input Features

The application uses eight input features for prediction:

| Feature | Description |
|---|---|
| MedInc | Median income of the area |
| HouseAge | Median house age |
| AveRooms | Average number of rooms |
| AveBedrms | Average number of bedrooms |
| Population | Population of the area |
| AveOccup | Average household occupancy |
| Latitude | Geographical latitude |
| Longitude | Geographical longitude |

##  Application Workflow

1. Users register through the Sign Up page.
2. Registered users log in using their credentials.
3. Flask validates the credentials using MySQL.
4. Users are redirected to their personalized dashboard.
5. Users enter the required housing information.
6. Flask processes the input using NumPy.
7. The trained Machine Learning model predicts the house price.
8. The predicted result is displayed on the result page.
9. Prediction details are stored in MySQL.
10. Users can view their previous predictions on the dashboard.

##  Database

**Database:** `housepriceprediction_app`

The application uses two tables:

**1. Users**
- Stores registered user information.
- Maintains username, email, password, and user ID.

**2. Predictions**
- Stores housing input features.
- Maintains the predicted house price.
- Associates each prediction with the respective user.

##  Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/harshwb20/House-Price-Prediction.git
```

**2. Navigate to the project directory**

```bash
cd House-Price-Prediction
```

**3. Create a virtual environment**

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

**4. Install dependencies**

```bash
pip install -r requirements.txt
```

**5. Configure MySQL**

Create the `housepriceprediction_app` database and configure your MySQL connection credentials in `app.py`. Ensure the required tables are available.

**6. Run the application**

```bash
python app.py
```

Open your browser:

```text
http://127.0.0.1:5000/
```
